01 · ORIGIN

업종의 사물을 장식이 아닌 구조로

데스크톱 창과 명령 팔레트를 핵심 인터페이스로 삼아, 개발자 포트폴리오의 기능 실행과 결과 확인 흐름을 한 화면에서 경험합니다.

DESKTOP CV 개발자 이력서는 개발자 포트폴리오 이용자가 처음 마주하는 질문을 화면 구조의 출발점으로 삼습니다. 보기 좋은 설명을 더하기 전에 사용자가 무엇을 확인하고, 어디에서 망설이고, 어떤 결과를 기대하는지 관찰합니다.

데스크톱 창, 명령 팔레트, 폴더 아이콘, 상태 바 같은 실제 소재는 분위기를 만드는 배경에 머물지 않습니다. 각 소재는 정보의 분류, 선택 기준, 진행 상태와 다음 행동을 알려주는 인터페이스가 됩니다.

이 템플릿은 가상의 브랜드를 위한 디자인이지만, 실제 프로젝트에서 콘텐츠를 확장하고 운영할 수 있도록 소개·서비스·사례·저널·문의 구조를 분리했습니다.
